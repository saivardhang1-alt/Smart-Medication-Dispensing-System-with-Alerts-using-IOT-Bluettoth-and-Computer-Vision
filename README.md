Smart Medication Dispensing System with Alerts using IoT, Bluetooth and Computer Vision

📌 Project Overview

The Smart Medication Dispensing System is an IoT-based solution designed to automate medication management and help patients follow their prescribed medication schedules.

The system uses ESP32, Bluetooth connectivity, RTC-based scheduling, sensors and Computer Vision to support medication dispensing, reminders and alerts.

🎯 Problem Statement

Patients may forget their medication schedules or take incorrect doses due to manual medication management. This project aims to improve medication adherence through automated reminders and a smart dispensing mechanism.

🚀 Objectives

- Automate medication dispensing based on scheduled timings.
- Provide alerts and reminders for medication schedules.
- Enable Bluetooth communication.
- Integrate IoT technology for smart medication management.
- Use Computer Vision to support medicine monitoring.

🛠️ Technologies Used

Hardware

- ESP32 Microcontroller
- RTC DS1307 Module
- LCD Display with I2C
- Buzzer
- Sensors
- Bluetooth Connectivity

Software

- Arduino IDE
- Embedded C/C++
- Python
- OpenCV
- Blynk Cloud

⚙️ Key Features

- Scheduled medication reminders.
- Automated medication dispensing mechanism.
- Bluetooth connectivity.
- Real-time clock-based scheduling.
- LCD status display.
- Audio alerts using a buzzer.
- Computer Vision integration.
- IoT-based monitoring.

🔄 Working Methodology

1. The RTC module maintains the medication schedule.
2. ESP32 processes the scheduled medication timings.
3. The system activates the dispensing mechanism at the configured time.
4. LCD displays relevant medication information.
5. Buzzer provides alerts and reminders.
6. Bluetooth connectivity supports communication.
7. Computer Vision assists with medicine monitoring.

🏗️ System Architecture

The system consists of an ESP32 controller, RTC module, display, sensors, alert mechanism, Bluetooth communication and Computer Vision components.
